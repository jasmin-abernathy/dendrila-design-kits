# Six directions, sans blog imposé

Les thèmes ne créent ni actualités, ni articles, ni catégories. Le site installé garde une seule page de bienvenue. Les pages de démonstration restent séparées du contenu utilisateur.

| Thème | Composition | Exemple |
|---|---|---|
| Simple illustré | Accueil compact, image carrée, services courts | Maison commune |
| Sobre et élégant | Introduction centrée, panorama en arche, images espacées | Maison Sillage |
| Images | Couverture immersive, mosaïque photographique, fond sombre | Portfolio Horizons |
| Minimal | Colonne de présentation et répertoire d’expertises, texte sobre | Studio Forme |
| Graphique | Affiche typographique, programme numéroté, aplats | Événement Les possibles |
| Éditorial | Couverture asymétrique, image verticale et liste d’expertises | Institut des territoires |

Le thème règle la présentation, pas le métier ni les modules. Toute page et tout bloc restent disponibles. Les exemples n’imposent pas leur structure aux contenus existants. Les couleurs et polices de marque restent personnalisables.

Le CSS visuel appartient au dépôt des thèmes. Le CSS d’intégration du CMS se limite aux adaptations communes du rendu, afin d’éviter deux directions graphiques concurrentes. Les captures du CMS utilisent des photos CC0 locales ; les aperçus statiques utilisent des photographies libres stockées localement avec leurs licences documentées.
