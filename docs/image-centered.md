# Centré sur les images

## Intention

Le média porte la première impression. Le texte reste court, lisible et secondaire par rapport aux photographies.

Les références validées montrent deux bornes complémentaires :
- un hero très immersif avec texte superposé à une image forte ;
- une version plus éditoriale où les images structurent la composition sans saturer toute la page.

Le design kit doit pouvoir couvrir les deux sans devenir un thème magazine.

## Signature visuelle

- hero plein cadre ou très dominant ;
- photographie utilisée comme structure, pas comme décoration ;
- statistiques sobres entre deux séquences visuelles ;
- galeries en mosaïque ou grille éditoriale ;
- cartes principalement pilotées par leur média ;
- CTA et footer plus sombres pour refermer la page ;
- peu d'ornements hors image.

## Mobile

Le hero conserve une seule grande image mais le dégradé se verticalise pour garder le texte lisible. Les galeries restent compactes et la première image conserve une importance supérieure.

## À éviter

- transformer chaque section en carte ;
- ajouter des formes décoratives indépendantes des médias ;
- imposer une palette sectorielle ;
- masquer un texte essentiel directement dans une photo sans contraste suffisant.
