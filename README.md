# Dendrila Design Kits

Bibliothèque de thèmes/fronts réutilisables pour Dendrila CMS.

Ce dépôt contient la couche de présentation : structure HTML/CSS, composants visuels, masques média et exemples. Les contrats de styles et tokens restent définis dans `jasmin-abernathy/dendrila-cms`.

Le premier thème de référence est `simple-illustrated`, construit à partir des enseignements de Materceleste mais sans identité, contenu ou logique métier propres à Materceleste.
