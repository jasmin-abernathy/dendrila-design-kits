# Starter / Kit de démarrage

Copy the files in this directory to themes/your-id. / Copier les fichiers dans themes/votre-id.
Change both IDs, labels, version, CSS scope and preview content. / Adapter les identifiants, libellés, version, sélecteurs et contenus.

The starter is not an installed kit and is not listed in catalog.json. Review the CMS design_style_id mapping before adding a catalogue entry. / Ce modèle n'est pas installé ; vérifier le mapping CMS avant inscription au catalogue.
